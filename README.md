# 苏游修改器 · 柳漪春涛正式版 v6

《苏丹的游戏》存档编辑器。**单个 HTML 文件，下载后断网可用**，不需要安装、不需要联网、不上传你的存档。

在线使用：<https://khb10533.github.io/suyou-save-editor/>

词库版本：游戏配置 `20260306160333`（卡牌 1294 · 事件 1863 · 仪式 1498 含卡位槽配置 · 标签 444 · 命运商城 50 · 成就 15）

## 功能

**🧮 计数器（原「名望」区升级）** ← v5 新增
- 名望只是计数器的一种。游戏里**大量事件和仪式都会读写计数器**，计数器又会作为条件决定后续走哪条分支
- 内置 **1248 个计数器的名称、出处与操作说明**（从游戏全部配置的引用点反推）
- **每个引用都注明它对这个计数器做了什么** —— 增加 / 减少 / 设为 / 条件判定，全局计数器会标「全局」
- **保留游戏源码里作者写的 `//` 注释**，例如 `"counter-7100001":1, //善名-1` 会显示成「减少1　// 善名-1」
- 支持按 **ID / 名称 / 引用它的仪式事件名** 搜索；可手动新增任意计数器
- 六项名望（善名/恶名/权势/侠名/灵视/金骰子）保留在顶部常用区，带清零、+50、一键拉满

**🎬 结局查看与修改** ← v5 新增
- 内置官方 **159 个结局**的 ID、标题、副标题、正文、成败类型（失败/小胜/大胜）
- **标注每个结局对应的图鉴编号与图鉴册名**（来自 `gallery_cg.json`，15 册，153/159 覆盖），例如 `211 征服者的牢笼 → 📚 图鉴 9《权力囚笼》`
- 可按图鉴册名搜索结局（如搜「权力囚笼」）
- **结局 ID 与对应的 CG 资源一一对上**（如 `over_cg/over_cg_101`），默认图会标注为「默认结局图」
- 显示存档当前的本局结局（`over_reason`），以及 `global.json` 里已解锁的结局列表（`overID`）
- 可按 ID / 标题 / 副标题 / 正文搜索，一键「设为本局结局」
- ⚠️ 界面上明确提示：**改结局能否在游戏里生效未经作者验证**，请先备份

**🔄 存档互转（手机端 ⇄ 电脑端）**
- 自动识别载入的存档来自手机端还是电脑端
- **存档体检**：逐项检查会导致读档报错的格式问题（缺字段、时间格式不对、对象缺字段等）
- 一键把存档转成另一端的格式再导出，**不改动你正在编辑的存档**
- 两端格式对照表清清楚楚写在界面上，转完还会列出具体做了哪些改动

- 手机端存档比电脑端多一个 `createTime` 字段（UTC 时间，结尾 Z）。电脑端存档没有它，
  手机端读档时解析不到就会报错读不出 —— 这就是存档转不了的原因。
- 转成手机端会自动补上 `createTime`；转成电脑端会去掉它。其余数据**一字不动**。

**卡牌 / 物品**
- 自动显示官方正确名字、称号、类型徽章与完整简介（内置 1294 张卡牌资料）
- 按分类筛选：角色 / 物品 / 苏丹卡 / 词库未收录 / 有装备的 / 有装备位的
- **独立分类标签页**：卡牌列表上方设有「全部 / 👤人物卡 / 📦物品卡」三个标签页
- **标签筛选开关**：可勾选「仅显示有追随者的卡」「仅显示有已拥有的卡」
- **官方初始数据展示**：卡牌展开页显示该卡在官方源文件中的初始名称、称号、类型和全部初始标签
- **添加卡牌时自动打标签**：人物卡自动打「追随者」，物品牌自动打「已拥有」
- 按名称、ID、存在时间、堆叠数、装备数排序
- 搜索覆盖官方名、称号、简介、类型、ID、UID、标签、身上装备的道具名、装备位
- 按名字添加任意卡牌；变体卡自动回退到基础 ID 取资料；输入序号可跳转并展开
- **卡牌的复制与删除按钮已移入卡牌展开页内**
- **事件的复制与删除按钮也已移入事件展开页内**（删除需要二次确认）

**装备位与装备**
- 查看每张卡的全部装备位，与官方设计对比，一键恢复官方配置
- 自由增删装备位（⚔️武器 / 👗服装 / 💎饰品 / 🐎驯兽）
- 已装备的道具按人物物品同样的格式展开
- 装备可移到手牌、复制、卸下删除；卡牌标题显示 ⚔️装备数/装备位数

**标签**
- 内置 444 条官方标签词库，含中文名、类型与说明
- 加标签时可搜索选择，输中文名或英文 code 都能搜到
- 已添加的标签不会重复出现在候选里

**事件 / 仪式**
- 显示官方正确名字与类型徽章（事件表 1863 条 + 仪式表 1498 条）
- **按名称添加仪式**：搜名字、地点或 ID，一键加进存档
- 添加时**自动按官方配置补齐卡位槽数量**，并列出每个槽的官方要求
- 仪式额外显示结局 / 战斗 / 宝藏徽章与所在地点，标题栏标注槽位是否与官方一致
- 空槽可直接**按名字搜官方词库填卡**
- **⚡ 强制进行事件开关**：一键切换 `new_born / is_show / start`，让加进去的事件能真正触发

**名望**
- 善名 / 恶名 / 权势 / 侠名 / 灵视 / 金骰子，直接改数值；每项带清零、+50
- 进阶：按 ID 或名称查改 `counter` 里的任意计数器项

**🎁 命运商城（`global.json` 独立通道）**
- 单独载入 / 下载账号全局档 `global.json`，与普通存档**完全独立**
- 命运点：总数 / 已用 / 剩余实时计算
- 列出全部 50 项官方加点，含前置解锁、互斥关系、解锁条件
- 筛选 + 搜索 + 手动填 ID 添加 + 一键全开 / 全关
- 🏆 成就解锁：15 项官方成就可逐个或一键解锁 / 取消

**图鉴查询**
- 卡牌 / 事件 / 仪式三个模式，可按类型与可堆叠状态筛选
- 卡牌可一键加入手牌，任意条目可复制 ID

**其它**
- 名称词典 557 条，全局字段与标签都显示中文名，可自行增补
- 源码页可直接查看和编辑存档 JSON
- 结构自动识别，兼容不同版本存档的字段布局
- 右下角悬浮**快速翻页滑轨**：拖动定位、一键置顶 / 置底
- 改动前建议先【导出备份】

## 已知限制

- **手机版游戏没有更新联动内容**，因此联动物品即使加进存档也不会生效。
- 存档里可能存在 MOD 添加的条目，官方配置里查不到，编辑器会标为「词库外」并原样保留。

## 使用

1. 打开 `index.html`（**用 Chrome / Edge**，手机上长按文件 → 打开方式 → 浏览器）
2. 点【📂 打开存档文件】选择你的存档 JSON
3. 改完点【💾 保存并下载】，把文件放回原位置

要换平台玩，就到【🔄存档互转】页转一下再导出。

存档位置随平台和版本而异，请自行确认后再覆盖，并**务必先备份原文件**。

## 从源码构建

仓库里的 `index.html` 就是成品，直接用即可。重新构建见项目内的组装脚本。
